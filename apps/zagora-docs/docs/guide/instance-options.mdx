---
title: Shorten procedures with instance options
description: The handler options object, and the two zagora() flags, disableOptions and autoCallable, that make procedures shorter.
---

The `zagora(config?)` factory takes two flags. Both flags are `false` by default.

| Flag             | Effect                                                                 |
| ---------------- | ---------------------------------------------------------------------- |
| `disableOptions` | The handler gets only the input arguments, without the options object. |
| `autoCallable`   | `.handler()` returns the procedure, without `.callable()`.             |

## The handler gets an options object first

By default, the first handler parameter is the options object. The table lists its fields.

| Field | Value |
| --- | --- |
| `context` | The initial context, merged with the `.callable()` context. The [context guide](/guide/context) has the details. |
| `errors` | One helper per declared error kind. The [typed errors guide](/guide/typed-errors) has the details. |
| `env` | The parsed environment variables. The [environment variables guide](/guide/environment-variables) has the details. |

```ts twoslash
import { z } from "zod";
import { zagora } from "zagora";
// ---cut---
const procedure = zagora()
  .context({ user: "bobby" })
  .errors({ NOT_FOUND: z.object({ id: z.string() }) })
  .env(z.object({ PORT: z.coerce.number().default(3000) }), {})
  .input(z.string())
  .handler((options, userId) => {
    // options: { context, errors, env }
    if (options.context.user !== "bobby") {
      throw options.errors.NOT_FOUND({ id: userId });
    }
    return `bobby found on port ${options.env.PORT}`;
  })
  .callable();
```

## The disableOptions flag removes the options object

With `disableOptions: true`, the input arguments are the only handler parameters. The handler cannot read the context or the env values, and it gets no error helpers. zagora still validates the env values on every call.

```ts twoslash
import { z } from "zod";
import { zagora } from "zagora";
// ---cut---
const upper = zagora({ disableOptions: true })
  .input(z.string())
  .handler((text) => text.toUpperCase())
  .callable();
```

## The autoCallable flag removes the callable step

With `autoCallable: true`, `.handler()` makes the procedure. There is no `.callable()` step. The context, the cache adapter, and the env values come only from `.context()`, `.cache()`, and `.env(schema, envVars)`.

```ts twoslash
import { z } from "zod";
import { zagora } from "zagora";
// ---cut---
const hello = zagora({ autoCallable: true })
  .input(z.string())
  .handler((_, name) => `Hello, ${name.toUpperCase()}`);

hello("bob");
// { ok: true, data: 'Hello, BOB', error: undefined }
```

## Both flags give the shortest form

With both flags, a procedure is one `.input()` call and one `.handler()` call. One instance can make many small procedures.

```ts twoslash
import { z } from "zod";
import { zagora } from "zagora";
// ---cut---
const za = zagora({ autoCallable: true, disableOptions: true });

/** Adds two numbers. */
export const add = za.input(z.tuple([z.number(), z.number()])).handler((a, b) => a + b);

/** Upper-cases every string. */
export const upperAll = za
  .input(z.array(z.string()))
  .handler((items) => items.map((item) => item.toUpperCase()));

add(5, 3);
// { ok: true, data: 8, error: undefined }
upperAll(["foo", "bar"]);
// { ok: true, data: ['FOO', 'BAR'], error: undefined }
```

Without the options object, the handler has no error helpers. Typed errors still work. Throw a plain object with a declared `kind`, and zagora validates it against the error schema.

```ts twoslash
import { z } from "zod";
import { zagora } from "zagora";
// ---cut---
const za = zagora({ autoCallable: true, disableOptions: true });

const findUser = za
  .errors({ NOT_FOUND: z.object({ id: z.string() }) })
  .input(z.string())
  .handler((id) => {
    throw { kind: "NOT_FOUND", id };
  });

findUser("42");
// { ok: false, isTypedError: true, error: { id: '42', kind: 'NOT_FOUND' } }
```

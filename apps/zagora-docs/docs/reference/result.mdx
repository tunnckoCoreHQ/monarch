Every call returns one of three shapes.

```ts
// Success
{ readonly ok: true; data: TOutput; readonly error: undefined }

// A declared typed error
{ readonly ok: false; readonly isTypedError: true; readonly error: { kind: "NOT_FOUND" } & NotFoundData | ... }

// A built-in error
{ readonly ok: false; readonly isTypedError: false; readonly error: InternalError | ValidationError }
```

The [typed error](/guide/typed-errors) shape exists only when the procedure declares an error map. The fields have these types:

- The `data` field has the output type of the output schema. Without an output schema, it has the awaited return type of the handler.
- A typed error has the output type of its schema, without its own `kind` field, plus `kind` set to the error key.
- In a procedure with an error map, the `key` field of a `ValidationError` has the union of the declared kinds as its type. Zagora sets `key` when the data of a typed error fails its schema.

## The ZagoraResult type

The `ZagoraResult` type from `zagora/types` builds these shapes.

```ts
type ZagoraResult<TOutput, TErrorsMap, TResolvedResult, IsTypedError = ...>;
```

To get the result type of a procedure, infer it from the procedure.

```ts twoslash
import { z } from "zod";
import { zagora } from "zagora";
// ---cut---
const getUser = zagora()
  .input(z.string())
  .errors({ NOT_FOUND: z.object({ id: z.string() }) })
  .handler((_, id) => ({ id }))
  .callable();

type GetUserResult = ReturnType<typeof getUser>;
```

For an async procedure, use `Awaited<ReturnType<typeof procedure>>`.

## Built-in error types

```ts
type ValidationError<TKinds = never> = {
  readonly kind: "VALIDATION_ERROR";
  readonly message: string;
  readonly issues: readonly StandardSchemaV1.Issue[];
  readonly key?: TKinds;
};

type InternalError = {
  readonly kind: "UNKNOWN_ERROR";
  readonly message: string;
  readonly cause: any;
  readonly stack: any;
};
```

The error object in a failed result is frozen with `Object.freeze`. The freeze is shallow, so nested objects stay mutable.

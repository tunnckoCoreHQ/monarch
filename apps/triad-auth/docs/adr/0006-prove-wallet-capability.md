# Prove wallet capability during use

All Passkeys begin without Wallet Capability. Identity Passkeys and Attached Passkeys may use any WebAuthn public-key algorithm accepted by Triad's verification library. Triad derives a Passkey Source Identifier from the SHA-256 digest of its canonical COSE public key instead of a key-type-specific representation. A Triad Account whose Identity Source is a Social Provider or Passkey may attach any user-verified Passkey; an EVM Identity Source cannot attach Passkeys. An Account Holder establishes Wallet Capability by selecting an Identity Passkey or Attached Passkey and completing one WebAuthn assertion that requests PRF output. The same browser operation derives one wallet and signs a bound capability envelope. Triad verifies the exact stored credential assertion and the Derived Wallet signature before it records Wallet Capability. A Passkey with Wallet Capability is a Wallet Passkey.

Wallet Authorization offers only Wallet Passkeys. Persisted Wallet Capability is a filter, not proof for a later request: every Wallet Authorization still requires fresh PRF output, verifies the exact selected stored Passkey assertion, derives one wallet, and verifies that wallet's signature over the Signing Envelope. A failed capability check does not persist a negative state.

After both proofs pass, Triad returns a Wallet Authorization Receipt signed by its existing ES256 JWKS key. The receipt uses the Client ID as audience and binds the Pairwise Subject, request ID, Derived Wallet address, Signing Envelope hash, wallet signature hash, namespace, Wallet Profile, Account Index, Derivation Path, applicable Chain ID, and lifetime. It lets the Client Application verify that Triad authenticated the account and accepted the exact wallet operation without creating a separate Triad signing-key system.

The supported Wallet Profiles include EVM with EIP-191 signatures, Solana with hardened SLIP-0010 Ed25519 derivation and Ed25519 signatures, Bitcoin Native SegWit with BIP-322 Simple signatures, and Bitcoin Taproot with BIP-322 Simple signatures. Bitcoin profiles always specify their network and address type.

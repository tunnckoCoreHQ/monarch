# ethscriptions-rescue

## 0.1.0

### Minor Changes

- [#137](https://github.com/tunnckoCoreHQ/monarch/pull/137) [`770ca76`](https://github.com/tunnckoCoreHQ/monarch/commit/770ca7661864ab7242b53ba4a40ce3fb6948333a) Thanks [@tunnckoCore](https://github.com/tunnckoCore)! - Add the `ethscriptions-rescue` CLI. It moves ethscriptions out of a compromised wallet with EIP-7702, while a sponsor wallet pays the gas. It takes ethscription ids, ethscription numbers, or `--all`, which finds every ethscription the wallet owns through `api.calldata.space`.
